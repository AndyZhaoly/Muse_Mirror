# Color reference

- A clear main color plus a supporting color and an optional accent is a reliable default, not a rigid three-color law.
- Multiple saturated large color blocks need an obvious hierarchy.
- Colors near the face affect perceived freshness; avoid absolute conclusions under warm, dark, or tinted lighting.
- Monochromatic outfits need differences in value, texture, or shape to avoid flatness.
- Formal contexts usually benefit from lower visual noise; casual contexts can carry one memorable accent.
- Small echoes between shoes, bag, belt, inner layer, or jewelry can increase completion.
- Color harmony is contextual: skin tone labels should not become deterministic or exclusionary rules.
